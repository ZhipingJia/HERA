# HERA
## HERA: A fully heterogeneous compute-in-memory memristor chip
This repository accompanies the manuscript "A fully heterogeneous compute-in-memory memristor chip for flexible AI processing" (Nature, under review, 2026).

The repository will host:

The affinity-aware mapping framework (logits-deviation profiling, EDP profiling, affinity ranking)
Experimental scripts for the Faster R-CNN object-detection demo
Experimental scripts for the PrivateLoRA cloud-edge collaborative LLM demo
The complete code will be released upon publication. For early access during peer review, please contact the corresponding authors.
